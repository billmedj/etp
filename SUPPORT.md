# ETP support

ETP is an open-source implementer draft. Community support is best effort. The
repository does not provide a service-level agreement, warranty, production
on-call service, or security certification.

## Use the correct channel

- Use GitHub Discussions for usage questions and design discussion when it is
  enabled.
- Use the bug-report template for a reproducible defect.
- Use the protocol-proposal template for a normative change.
- Use a regular issue for a documentation correction.
- Follow [SECURITY.md](./SECURITY.md) for a vulnerability.
- Follow [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md) for a conduct report.

Do not place credentials, private data, customer configuration, or exploit
details in a public channel.

## Reproduction information

Include:

- the commit or version;
- operating system and tool versions;
- the smallest input that reproduces the result;
- the exact command;
- expected and observed behavior;
- sanitized logs or conformance output.

Only environments named in continuous integration and release notes are tested
environments. A passing local test does not establish production support for a
cloud, cluster, identity system, or deployment design.

No commercial support channel is offered through this repository.
