# Changelog

This file records user-visible changes to ETP.

## Unreleased

### Added

- Core 0.1 records, schemas, canonical encoding, and lifecycle rules.
- Portable conformance vectors and reference profile vectors.
- Rust and TypeScript verification implementations.
- Rust authority, SQLite, executor, and command-line components.
- Conditional HTTP and Kubernetes JSON Patch reference profiles.
- 23 Lean theorem declarations and one bounded TLA+ lifecycle model.
- Evidence, language, and publication checks.

### Changed

- Assigned versioned schema and profile URIs under the project GitHub Pages
  namespace.
- Standardized public terminology and claim boundaries.

### Security

- Defined single-use grant claims, durable dispatch markers, unknown outcomes,
  and append-only reconciliation.

No public ETP release exists yet.
